## 📝 Kuis Singkat

### 1. Next.js adalah...

**Jawaban:** _(Next.js adalah framework berbasis React yang digunakan untuk membangun aplikasi web modern, termasuk aplikasi full-stack, dengan fitur tambahan seperti routing, optimasi performa, dan konfigurasi otomatis)_

### 2. Mana yang TIDAK perlu di-install manual di Next.js?

**Jawaban:** _(React Router tidak perlu di-install manual, karena Next.js sudah memiliki sistem routing berbasis file atau folder)_

### 3. Saat install Next.js, agar menggunakan JavaScript (bukan TypeScript), kita harus pilih...

**Jawaban:** _(Pilih No pada pertanyaan “Would you like to use TypeScript?” saat proses instalasi Next.js)_

### 4. Apakah komponen React bisa dipakai di Next.js?

**Jawaban:** _(Ya, bisa. Next.js menggunakan React sebagai dasar, sehingga komponen React tetap dapat digunakan di dalam proyek Next.js)_

### 5. Sebutkan minimal 3 fitur yang Next.js berikan di atas React biasa!

**Jawaban:** _(
    1 File-based routing, sehingga halaman dibuat berdasarkan struktur folder dan file.
    2 Optimasi gambar menggunakan komponen Image.
    3 Konfigurasi otomatis untuk tools seperti bundler dan compiler.
    4 Dukungan full-stack, termasuk pembuatan halaman dan server-side logic.
    5 App Router, layout, dan routing modern berbasis folder)_

## ✏️ Jawaban Latihan

### Latihan 1 — Halaman Utama

_(Halaman utama pada Next.js biasanya dibuat pada file)_

### Latihan 2 — Halaman About

_(Halaman About dapat dibuat dengan membuat folder about, lalu menambahkan file page.js di dalamnya)_

### Latihan 3 — Tantangan: Bandingkan Routing

_(Pada React biasa, routing umumnya membutuhkan library tambahan seperti React Router. Developer harus mengatur route secara manual di dalam kode aplikasi.

Pada Next.js, routing sudah tersedia secara otomatis melalui sistem file dan folder. Misalnya, file app/page.js akan menjadi halaman utama /, sedangkan app/about/page.js akan menjadi halaman /about. Dengan demikian, routing di Next.js lebih sederhana karena mengikuti struktur folder proyek.)_
